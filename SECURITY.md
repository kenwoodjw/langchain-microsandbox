# Security policy

## Supported versions

Only the latest released version receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Submit a private
security advisory through the repository's **Security** tab. If private
reporting is unavailable, contact the maintainer through
[their GitHub profile](https://github.com/kenwoodjw) before disclosing details
publicly.

Include affected versions, reproduction steps, impact, and any suggested
mitigation. Please allow reasonable time for investigation and a coordinated
release.
